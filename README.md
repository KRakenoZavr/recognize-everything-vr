# recognize-everything-vr

Point at any real object with your hand or your gaze, see it highlighted, and open a
context menu that describes it. Written in Rust. First target: Meta Quest 3 / 3S; the core
is client-agnostic so phones, tablets and webcams can use it too.

**Status:** Phase 0, skeleton. Architecture and roadmap only; no feature code yet.
